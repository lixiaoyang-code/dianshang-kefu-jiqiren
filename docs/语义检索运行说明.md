# 本地语义检索 V0.2

已接入真实神经网络句向量模型，不是用相似字符串冒充向量检索。原问答、字段匹配优先；无法匹配时，使用当前已确认商品范围内的向量候选。答案从现有知识/固定话术原文返回，不让模型改写用户指定话术。

模型采用Sentence Transformers多语言MiniLM的int8 ONNX版本，CPU运行。模型数据固定版本、模型文件校验SHA256；下载后推理不需要联网、不需要API Key、不发送客户资料。模型来自[官方模型仓库](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)，按官方attention mask均值池化产生句向量。没有新增数据库或微服务。

## 当前机器

模型已下载到 `models/minilm/`，当前系统Python的运行库已可用。用系统Python重启服务后，`/api/health` 应返回 `semantic: ready`。网页右上角也显示是否就绪。

若用自己的虚拟环境，先安装可选语义依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-semantic.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

完整新版压缩包包含模型数据。模型在Git中忽略，不提交大权重文件。

## 模型不存在时

基础Mock和规则问答继续运行，健康检查显示 `model_missing`，不会伪称语义检索成功。安装依赖后可下载：

```powershell
python scripts/download_semantic_model.py
```

国内官方源连接困难时，可显式指定镜像（本次使用镜像下载，固定版本和模型SHA256校验）：

```powershell
$env:HF_ENDPOINT='https://hf-mirror.com'
python scripts/download_semantic_model.py
```

下载的是数据文件，不执行仓库自定义Python代码。模型118 MB、分词器约9 MB；启动时建立内存索引，后续请求复用。修改知识或问答后重启即重建，无需手工更新向量数据库。

## 参数与调试

`.env` 可配置：

```dotenv
SEMANTIC_MODE=auto
SEMANTIC_MIN_SCORE=0.68
SEMANTIC_MIN_MARGIN=0.07
SEMANTIC_TOP_K=5
```

设 `SEMANTIC_MODE=off` 可关闭。默认须最高候选分数达到0.68，且与第二候选至少相差0.07，才自动发送。分数是相关性余弦分数，不是答案正确率。阈值只是初始设置，不能视为经过真实客户数据校准。

调试中 `retrieval.method=semantic_onnx` 表示实际向量命中，`debug.semantic` 展示候选ID、来源、分数和差距。`low_confidence` 代表拒答；`guard_rejected` 代表多问题、数字参数或敏感承诺拦截。商品未确认不跨商品猜测，承重/甲醛/保证等不会借语义检索绕过未核实状态。同义问法命中同一话术后，原去重机制继续生效。

## 验证与限制

- 142条自动化测试通过，包括原134条以及8条真实模型检索测试。模型未下载时，8条模型测试会明确跳过，不当作已验证。
- `python scripts/evaluate_semantic.py` 运行15条固定样例，7条期望命中、3条商品问法保守拒答观察、5条无关/禁止问题，结果保存 `docs/semantic_evaluation.json`。本次15条符合预期，其中3条仍不能自动回答，不代表15个客户问题全部解决。
- 这些问法未写入索引种子；测试集很小，不代表真实售前准确率，也不是完全独立的盲测数据集。
- 实际HTTP验证：Mock模式、语义ready，“小狗联名款杆子容易倒吗”命中stability并原样返回稳固话术；该单次本机请求约11 ms，不代表普遍延迟。
- 未实现BM25/向量RRF融合、学习重排序或自由生成。当前是规则优先+向量补充，下一步可在真实问法评测之后增加混合融合。
- 临近参数、多个问题、陌生承诺仍可能拒答。知识库后续补充即可扩展现有字段/问答，但新的业务主题可能需补充索引问题示例。
