# 数据看板

公网入口：<https://14.103.103.60/statistics>，仅管理员可访问。咨询测试、知识库、资料库的导航均已加入入口。管理员账号沿用原账号。

核心指标按客户消息统计：

| 指标 | 口径 |
| --- | --- |
| 应答率 | 实际发送业务答案／有效消息；澄清、等待提示和 RAG 建议不计业务应答 |
| 转人工率 | 系统判定需人工核实或处理／有效消息；沿用用户要求，与“需人工处理率”同义，不代表真实人工已接管 |
| 意图识别率 | 明确识别出客户意图／有效消息；不等于识别正确率 |
| 准确率 | 人工评价“正确”／已评价业务答案；部分正确不计完全正确；没有评价时显示“—” |

默认排除问候、感谢、肯定、告别，可勾选包含互动消息。重复抑制不计入四项核心指标分母，数量单独展示。自动发送售后接待话术后仍需要人工处理的消息可同时计入应答和转人工，两率不互补。系统失败单列，不冒充知识缺失或真实人工转接。

支持今天、近7天、近30天、全部时间，按商品筛选；下方展示每日消息/应答、转人工及异常原因、原问题/实际答复/诊断依据。逐条答复可评价为正确、部分正确、错误，也可清除评价。评价覆盖率提醒抽样不足；准确率依赖人工评价质量，并不等同于客观全量准确率。

持久记录位于日志卷的 `/app/logs/statistics.sqlite3`。每条最终诊断结果新增中国时区时间戳，按 request_id 去重保存，人工评价独立保存。服务重启时导入现存 `events.jsonl*`，不会重复计数，也不覆盖已有评价。清除记忆或重置会话不清除统计。RAG 及等待提示不进入统计表。

旧日志缺少时间戳，不能反推出日期，因此只在全部时间中展示。已被日志轮换删除的历史记录无法还原。部署验收提问也属于测试记录。当前数据属于测试流量，不等同于线上真实客户经营指标。
