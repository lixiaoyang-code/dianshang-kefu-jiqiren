# 知识库管理页面

地址：http://127.0.0.1:8002/knowledge

也可从咨询测试页顶部的“知识库管理”进入。

## 查看和维护

1. 左侧选择纯色款、全伸缩款、小狗联名款、免安装款，或店铺通用、跨款推荐。
2. 输入客户原声、答案关键词或场景名称搜索，也能按分类、启用状态筛选。
3. 点击“编辑”，每行填写一个问法，修改标准答案，选择关联图片。
4. 点击“保存并生效”。已有会话仍保留，更新后的资料和检索索引立即生效。
5. “新建问答”可以建立新的商品专属、通用政策或跨款推荐；默认待核实。

已有条目保留原始商品关联和溯源字段，避免破坏规则；需要其他商品范围可新建问答。
图片选择器提供当前 FAQ 已关联的本地素材，可勾选或取消；新图片上传尚未提供。
点列表里的配图可打开原图。原始文件不修改。

## 状态与保存

- 已启用：参与自动回复。
- 待核实、人工处理、已停用：不作为该条目的自动回复答案。
- 页面状态表示知识审核状态；不是订单的售前、发货中、发货后状态。
- 同一个意图可能有多条旧记录，停用某一条不等于停用全部相关问答。
- 页面修改的是 `data/faq.json`。每次成功保存前，原文件备份至 `data/backups/`。
- 同时开多个管理页面，过期页面保存会提示刷新，避免覆盖别人刚保存的资料。
- 启用但答案为空、问法为空、非法商品或图片路径会被拒绝，原资料保留。
- 保存前重新准备知识和索引；写入使用临时文件原子替换。

当前页面是本机管理工具，服务仅监听 127.0.0.1。三层场景优先级、订单状态条件、
原声训练工作台和新图片上传留到下一轮，不会在界面里显示尚未生效的配置。

## 运行与验证

在项目目录运行：

`python -m uvicorn app.main:app --host 127.0.0.1 --port 8002`

共 196 项本地自动化测试通过，包括保存生效、备份、并发版本冲突、停用、
新增问答、商品过滤和图片路径校验。测试使用临时 FAQ 文件，没有覆盖真实话术。
浏览器已验证搜索、编辑窗口、原话与配图保存，以及成功提示。
