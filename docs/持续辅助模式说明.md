# 持续辅助模式（2026-10-13）

本次业务调整以用户最新说明为准：解答一个疑惑，必要时接一个简短追问；客服全程值守。真实商品库开启 `continuous_assist`，虚构商品库仍用于原先异常和人工状态回归测试。

## 客户回复行为

- 确定事实简短回答，一般1–2句；尺寸长宽对应时可肯定回复。
- 801/802/804帐纱为宽90×长190，高度90/110/120 cm；803为90×190×110 cm，长宽均±4 cm可调。
- 90×190适配问句使用已确认商品的帐纱尺寸，回复“可以的亲，90×190和这款帐纱长宽对应”，多高度款接“您需要多高的款呢？”；不是对安装空间、承重或特殊床型的整体保证。
- 803按三开门回答，不把通用单开款介绍误当成803在售款。
- 资料不足、模型错误不发客户回复，返回 `send_to_customer=false`、空 `answer`，原因只在工作台和日志显示。
- 下一条消息继续处理，不锁定会话；页面去掉“恢复AI”和“人工接管”按钮。
- `suppressed` 表示有意留给客服处理，与系统 `error` 区分。两者均不发送故障说明给客户。

## 物流话术

采用用户确认的短版规则：京东物流由京东仓配送，预计当天/次日/隔日，以页面预计时效为准；未显示京东物流通常24小时发出、特殊情况48小时，不能解释成该时间内到货。不知道配送方式时只问“页面有显示京东物流吗？”

客户要求今天发或加急时，回复协助申请加急，不声称已向仓库下达指令。这版没有仓库操作接口。全国77仓数量及非京东东莞/南通仓等原话未用于简短客户回复，本地不做实时仓库查询。

## 等待提示（本地模拟）

对于未自动回答的消息，自接收计时25秒后可发送一次：

> 亲亲，抱歉让您久等了，您的问题这边正在核实，稍等一下哈。

页面通过后端校验该请求是否仍未处理；已发过不会重复。客服点击“人工已回复 · 取消等待提示”、新建会话或后续已产生正常回复时会取消旧等待提示。连续未处理问题只保留最近一次等待提示。

此功能依赖本地页面保持打开和浏览器计时，不保证京东30秒指标；尚未接入平台消息时间、人工回复事件及可靠后台调度。模型默认12秒超时，出现异常后仍可以进入本地等待提示流程。页面网络完全断开时不能保证发送。
